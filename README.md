# Mesa Marcada ♠️

Projeto para organizar noites presenciais de Poker e Blackjack entre amigos.

## Versão atual

MVP **v0.5 (protótipo)**. Recursos: salas, sessões, confirmações de presença, enquetes, controle de fichas, despesas, rankings e tutoriais. Interface escura inspirada em um baralho preto com detalhes em azul e vermelho.

A aplicação ainda usa **dados locais de demonstração**. Não há login real, sincronização entre usuários ou integração Supabase. Não usar como ambiente de produção.

## Desenvolvimento

A estrutura Next.js será adicionada neste primeiro envio.

## Cuidados

Nunca publique senhas, arquivos `.env`, tokens ou dados financeiros privados. Valores em reais e fichas são registrados separadamente e não representam processamento de pagamentos.
